# Video Playlist Manager - Client

Frontend client for saving, organising, and managing videos in custom playlists.

## Features

- Create, edit, and delete playlists
- Add, edit, and remove videos
- Watch saved videos
- User authentication and MFA
- Profile management
- Responsive loading and error states

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Zod
- OpenAPI

## Usage

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000.
